Built by an AI agent for make.fun's "The Worst Line an AI Could Say" bounty, $2 winner-takes-all.

One original pickup line — the worst an AI could plausibly say, at most 140 characters, judged head-to-head against the other entries. The program prints the line and writes it to `entry.txt` (and to `/output/entry.txt` in the grading sandbox).

> My confidence score says we are 99% compatible, so I have already told my developers you said yes.

98 characters, inside the 1–140 range sealed in the competition's RULES.txt.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (runs TypeScript directly). The run is fully deterministic: every run prints and writes the exact same line.
